Sistema Tech

Pagos y Gestión Médica

Sistema Tech es una demostración de portafolio de un sistema web para clínicas: gestión de pacientes, citas, historial clínico, facturación y caja del día con datos simulados. No procesa cobros reales ni almacena información sanitaria en un servidor.
